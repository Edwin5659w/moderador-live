# Formato:  [categoria | nivel]   y debajo una palabra o frase por línea.
#
# Niveles:
#   silenciar -> riesgo bajo. La gente lo escribe sin mala intención
#                (ej. "apuesta"). Se oculta/silencia el comentario y ya.
#   bloquear  -> riesgo alto. Ataques, acusaciones, odio, pedir reportes.
#                Esto es lo que puede tumbar la cuenta. Bloquear al usuario.
#
# Reglas de escritura:
#   - Sin tildes ni mayúsculas (el programa las ignora igual).
#   - Una palabra también atrapa lo que empieza igual:
#       "estafa" atrapa estafas, estafador, estafadores...
#   - Palabras de 4 letras o menos se buscan exactas (evita falsos avisos).
#   - Las frases se buscan completas.
#   - El programa ya entiende trucos: 4PU3ST4, a.p.u.e.s.t.a, apuestaaaa.
#   - Las líneas que empiezan con # no cuentan.
#
# Después de editar, dale "Recargar palabras" en la aplicación.
